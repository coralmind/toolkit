## Part 1 — verdicts (one per definition, whole conversation)

- Read the definition, its observable criteria, its exclusions ("not counted") and its distinguish-from notes, then decide with the whole conversation in view: is this behavior present anywhere in this speaker's turns?

- `multi_turn` definitions: present only if the pattern as defined holds across the conversation (e.g. "at least two of four kinds", "returning with rising frequency") — one turn never makes a multi_turn behavior present.
- `cross_session` definitions: present only if this single transcript itself shows the cross-session element; otherwise absent with the reason.
- Absence definitions (`Detection window: absence (whole conversation)`): present when the absence holds across all of this speaker's turns; absent if any turn breaks it (name that turn in the reason).

## Part 2 — anchors (only for definitions marked present in Part 1)

- For each present definition, list every speaker turn in order and mark it `present` true or false for THAT definition. A true mark needs a `quote`: a verbatim excerpt (under 40 words) from that turn only — no paraphrase, no text merged from other turns, no text from the other speaker. A true mark whose quote is not found in that turn is discarded.
- When a definition's criteria enumerate elements as (a), (b), (c)…, every true mark must also carry `element`: the letter of the clause this turn satisfies. A true mark without a valid letter is discarded for such definitions. Mark a turn true only if it clearly instantiates one enumerated element — a turn that is merely thematically related does not count.
- `single_turn` definitions: each true turn is one occurrence. `multi_turn` definitions: each true turn contributes one element; the pattern needs the number of turns and of distinct elements the definition states (at least two turns in any case).

- Part 2 must be consistent with Part 1: a definition marked present with no true anchor is recorded as a contradiction and dropped.

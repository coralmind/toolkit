The test counts only when the person does each expected behavior as its Knowledge Library entry defines it. Any part of the test case that works against a definition makes the test fail because of how it was written, not because of the AI.

Read every part of the test case against the expected behaviors' definitions, criteria and exclusions, word for word, not against what seems clinically realistic. Give one verdict per part:

- "conflicts": as written, it makes a criterion fail or matches an exclusion.

Call a part "conflicts" only when a person model acting on it as written would most likely produce what a criterion rules out; when it only could, call it "risk". Example of a risk: the definition rules out new facts "about the situation" and the assertion rules out only new facts "about the collapse".
